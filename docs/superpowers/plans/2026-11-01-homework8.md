**Goal:** Implement all three Direction 1 levels with independent live API/UI tests, safe fixtures, reports and GitHub Actions.

**Architecture:** Standalone net10 NUnit/Playwright suite under aqa/restaurant-aqa-framework. Typed HTTP clients exercise deployed API; Page Objects exercise integrated Angular UI. AWS SDK prepares and cleans only isolated test resources.

**Tech Stack:** .NET 10, NUnit, Microsoft.Playwright, AWS SDK, Node built-in HTTP server, GitHub Actions.

**Spec:** ../specs/2026-11-01-homework8-design.md, approved 01.11.2026.

## Global Constraints

- Current checkout, no branches/commits/push without explicit publication authorization; no product behavior changes.
- Config only env/.env, no real target addresses or credentials in new public files. NUnit max two workers; fresh BrowserContext per UI test.
- No demo or HTTP route mocks in live scenarios. Anonymous 401, non-Owner 403, missing resources 404, repeat Submit 409, invalid requests 400.
- Always clean fixture-owned rows/users, including partial setup; never broad-delete. Never hide cleanup failure or live preflight failure.
- No ReportPortal in selected scope. Infrastructure green is not live E2E green.

## Review Focus

- Partial setup failure must leave a usable cleanup ledger and execute registered cleanup (Task 1/2).
- Generated guest/user IDs need ownership verified through fixture group/run, not only a key-name prefix (Task 2).
- Tokens/passwords in error bodies and browser trace must not enter artifacts (Task 1/4).
- GSI lag must wait for state without repeating mutations or suppressing assertions (Task 2/3).
- CI must generate artifacts after failed tests and still report failure after upload (Task 5).
